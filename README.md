# 🎓 GetMyCollege

**GetMyCollege** is a desktop-based college discovery and management application developed using **Java, JavaFX, and Firebase Firestore**. The application is designed to help students find and explore college information through a simple, interactive, and user-friendly graphical interface.

The project demonstrates the use of **Core Java, JavaFX GUI development, Firebase Firestore, Maven, and object-oriented programming concepts** to build a real-world desktop application.

---

## 📌 Project Overview

Choosing the right college can be difficult because students often need to compare information such as college names, locations, courses, facilities, and other details.

**GetMyCollege** aims to provide a centralized platform where college-related information can be stored and accessed easily.

The application uses **Firebase Firestore** as its cloud database, allowing college information to be retrieved dynamically instead of storing all information directly inside the application.

---

## 🎯 Objectives

The main objectives of GetMyCollege are:

- To provide an easy-to-use college information platform.
- To allow users to explore available colleges.
- To display college information in a structured format.
- To store and retrieve college data using Firebase Firestore.
- To provide a graphical user interface using JavaFX.
- To demonstrate practical implementation of Core Java concepts.
- To use Maven for project and dependency management.
- To develop a scalable foundation for a future college-search platform.

---

## ✨ Features

### 🏫 College Information

Users can explore available college information through the application.

### 🔍 College Search

The application can be extended to allow users to search for colleges based on different parameters such as:

- College name
- Location
- Course
- University
- Category

### 📚 Course Information

The system can display information related to courses offered by colleges.

### 🗃️ Cloud Database

College data is stored using **Firebase Firestore**, allowing the application to access cloud-based information.

### 🖥️ JavaFX User Interface

The application provides a desktop graphical user interface developed using JavaFX.

### 🔥 Firebase Integration

Firebase Firestore is integrated with the Java application to perform database operations.

### 📦 Maven Project

Maven is used to manage dependencies, build the project, and maintain the project configuration.
